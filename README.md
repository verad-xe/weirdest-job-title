One original job title for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty — a real-sounding senior role with one hilariously specific twist:

> Senior Vice President of Apologizing to Geese

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/weirdest-job-title-out python3 main.py
```

This writes the title to `$MAKEFUN_OUTPUT_DIR/entry.txt` (45 characters, within the 60-character limit).
